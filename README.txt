AUTOHAUS Premium Motors website
================================
Files:
- index.html      Home / search / featured cars
- inventory.html  All 9 car cards, search, category filter and sorting
- finance.html    Financing information
- services.html   Services
- about.html      About AUTOHAUS
- contact.html    Contact and demo test-drive form
- style.css       Shared responsive styling
- script.js       Mobile navigation, search filters and contact form demo

How to run:
1. Extract the ZIP.
2. Open the AUTOHAUS_Website folder in VS Code.
3. Open index.html using Live Server.
4. Images load from Unsplash and therefore require an internet connection.
5. The contact form is front-end only; it does not send/store messages until connected to a backend.
6. Replace example contact information before publishing.
